核心功能

存档转模型.obj

招牌能力：把我的世界存档一键导出成带贴图的 OBJ + MTL，导完直接在手机上 3D 预览，也可以丢进 Blender、Blockbench 继续加工。

  • Mineways C++ 内核原生编译进 APK，全程不经过服务器
  • OBJ / MTL / GLB / STL / bbmodel 互转，.blend 也能转出
  • 离线 3D 预览，不用在电脑装任何软件
world.dat → model.obj

真实世界生成arnis

拉取真实地图数据，在手机里把一座真实城市生成 Minecraft 存档。配套离线种子地图，不联网也能查地形。

  • arnis 内核（Rust 原生库）在本地完成生成
  • 离线种子地图：群系、结构、要塞、史莱姆区块
  • 像素地图存档：玩家地图搜到就能下载
real map → world save

手机跑完整 Blender.blend

不用电脑：应用在本地装官方 Linux 版 Blender 并直接渲染 .blend 工程，四道兜底保证出图——产物校验、逐帧续渲、降级重试、视频回退。

  • 渲染全程离线，断网可用
  • Mine-imator 动画工作室：建模、摆动作、渲染出片
  • .blend → GLB / OBJ / STL 转换一条命令的事
blender -b scene.blend -a

剪辑与发布.mp4

OpenCut 剪辑器整个打包在本地：多轨时间轴、文字描边阴影、出入场动画，导出 MP4。发出去之前，用剪辑标识清除把剪映、快影、必剪写进视频元数据的标识原地抹掉。

  • 标识清除不转码：画面与音频一个字节都不动
  • 先看清再动手：每条元数据列出来，勾哪条清哪条
  • 产物写回相册，原件不作任何改动
metadata scrub · 不转码

常见问题

AFF 工具箱是什么？

AFF 工具箱（AshenFlame Foundry）是一款安卓端我的世界创作工具箱，把「存档导出 → 世界生成 → 渲染动画 → 视频剪辑 → 发布」整条创作链装进一部手机：26 个本地工具全部离线优先，另收录 132 个在线站点并内置 22,327 条汉化。

支持哪些版本的存档？

Java 版、基岩版、网易版的存档都可以导出成带贴图的 OBJ + MTL 模型；基岩世界可以用内置的 Chunker 转成 Java 版；.blend、GLB、OBJ、STL、bbmodel 等格式之间也能互相转换。

需要联网吗？

26 个本地工具全部离线优先：存档导出、Blender 渲染、视频剪辑、种子地图、格式转换都不依赖服务器。只有「在线站点」板块的 132 个网站需要浏览器联网打开。

收费吗？

本体免费、源码遵循 GPL-3.0 开源。少数重度功能（视频剪辑、剪辑标识清除、文件修复等）按激活码或白名单账号开放，其余工具全部免费使用。

怎么下载安装？

到 GitHub Releases 页面下载 APK（Android 8.0 及以上），允许安装未知来源应用即可。覆盖安装不会丢失工程、相册产物与登录态，安装包校验值见 Release 说明。
