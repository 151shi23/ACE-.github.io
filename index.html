AFF 工具箱负责哪一段工作？

从 Java、基岩、网易存档导出开始，接真实世界生成、模型转换、Blender 渲染、Mine-imator 动画、OpenCut 剪辑与 GIF/格式处理。

支持哪些版本的存档？

Java 版、基岩版、网易版存档都可以导出成带贴图的 OBJ + MTL 模型；基岩世界还能通过内置 Chunker 转成 Java 版。

必须联网才能使用吗？

本地工具全部离线优先。存档导出、Blender 渲染、视频剪辑、种子地图与格式转换不依赖服务器；只有在线站点板块需要联网。

所有功能都免费吗？

本体免费并遵循 GPL-3.0 开源。少数重度功能按激活码或白名单账号开放，其余工具免费使用，目录中已标明开放方式。

如何安装与更新？

下载 Android 8.0 及以上版本的 APK，允许安装未知来源应用即可。覆盖安装不会丢失工程、相册产物与登录态。
